# NOTE FOR MANAGED WINDOWS MACHINES
#
# Application Control on some machines blocks uuid_utils' newer native wheels by
# file hash, and langchain_core hard-imports uuid_utils with no fallback, so a
# blocked wheel makes the whole project unimportable rather than merely failing a
# test. The workaround is to downgrade that one wheel AFTER installing:
#
#     pip install --no-deps uuid_utils==0.10.0
#
# It deliberately does not live in this file. langchain-core and langsmith both
# require uuid-utils>=0.12.0, so pinning 0.10.0 here is unsatisfiable -- pip
# either refuses to resolve, or backtracks to an ancient langchain-core whose
# Reviver has no allowed_objects and which langgraph then crashes on at import.
# That is what turned CI red, with a TypeError naming neither package.
